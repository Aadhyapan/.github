# Aadhyapan

**Great software shouldn't sit behind a price tag.**

Aadhyapan is a Nepali software project whose Android app was once sold for around $100. Today it is open source, free to download, and free to build on.

[**Download the app**](https://aadhyapan.github.io/) · [Browse the source](https://github.com/Aadhyapan/Aadhyapan-Android-Client-Source-Code) · [Website](https://aadhyapan.com)

</div>

---

## Our story

Aadhyapan started as a commercial product from a software development company in Nepal. The Android client was sold to customers for around $100. We decided to give it back to the community: the full source code is now public, and the app is a free download for everyone.

The release was made by [**Raman Chapagain**](https://ramanchapagain.github.io/), who opened the code so developers, students, and small teams could learn from a real commercial app instead of starting from scratch.

## Get the app

Grab the latest APK from **[aadhyapan.github.io](https://aadhyapan.github.io/)**. You may need to allow installs from unknown sources on your Android device. Always download from the official site.
